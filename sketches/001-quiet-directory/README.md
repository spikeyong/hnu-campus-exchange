## Variant: 清晰目录

### Design stance

用安静的目录式浏览承接高频搜索，把身份和交易状态放进持续可见但不抢占内容的位置。

### Key choices

- Layout: 顶部全局导航 + 紧凑筛选 + 三列结果，详情使用侧边检查器。
- Typography: 中文人文无衬线，28px 页面标题，14px 高密度正文。
- Color: 延续海大互助的青绿主色，以橙色仅提示价格和待处理状态。
- Interaction: 页面切换、类型筛选、详情侧栏、交易双方确认、认证挑战码。

### Trade-offs

- Strong at: 上手快、搜索效率高、与当前实现距离最近。
- Weak at: 我的交易仍是二级空间，紧急待办的压迫感较弱。

### Best for

- 首次使用比例高、以浏览资源和技能为主要入口的学生端。
