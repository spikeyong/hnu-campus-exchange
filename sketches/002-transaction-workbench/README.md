## Variant: 交易工作台

### Design stance

把平台设计成任务工作台，任何时刻都先回答“这笔交易现在在哪里，我下一步做什么”。

### Key choices

- Layout: 左侧主导航 + 交易队列 + 中央工作区 + 右侧协议检查器。
- Typography: IBM Plex Sans 风格的清晰数据排版，状态和编号使用等宽字体。
- Color: 深色导航、灰阶工作区、青绿单一主操作色，状态色语义化。
- Interaction: 选择交易、确认已收到、切换广场与认证、折叠移动端导航。

### Trade-offs

- Strong at: 交易闭环最清楚，管理端、举报和认证审核可自然复用。
- Weak at: 默认密度较高，纯浏览用户需要适应。

### Best for

- 平台进入真实交易阶段后，需要反复处理请求、协议、交付和争议的用户。
