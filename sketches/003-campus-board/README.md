## Variant: 校园双轨看板

### Design stance

资源与技能并列成两条校园互助轨道，用更亲和的内容节奏鼓励发现，同时保留严格的交易状态推进。

### Key choices

- Layout: 紧凑侧栏 + 双轨内容列 + 横向交易状态看板。
- Typography: 稳定无衬线与轻量标签，避免营销式大标题。
- Color: 青绿、珊瑚橙与中性灰分工，颜色只承担类别和状态，不做装饰渐变。
- Interaction: 类别切换、详情抽屉、交易看板、认证步骤展开。

### Trade-offs

- Strong at: 校园感更强，资源与技能权重清楚，发现体验有记忆点。
- Weak at: 双轨布局在窄屏会退化为分段列表，不适合高密度管理台。

### Best for

- 希望首页更有校园社区感，但仍需要明确交易规则的学生端广场。
